# IFBE — International Federation of Beauty Experts
### الموقع الرسمي للاتحاد الدولي لخبراء التجميل — theifbe.com

موقع ثنائي اللغة (عربي/إنجليزي) يتضمن:
- صفحات الموقع العامة: الرئيسية، من نحن، البرامج، الخدمات، المكاتب الإقليمية، التواصل
- نظام **التحقق من الشهادات** للعامة
- **لوحة تحكم الطالب**: برامجه، شهاداته، فواتيره، ملفه الشخصي
- **لوحة تحكم الإدارة** للتحكم الكامل: نصوص الموقع، البرامج، الخدمات، المكاتب، الطلاب، الشهادات، طلبات التقديم، الاستفسارات، المدفوعات، المشرفون، الإعدادات والشعارات

الاستضافة على **GitHub Pages**، وقاعدة البيانات وتسجيل الدخول على **Supabase** (الخطة المجانية تكفي للبداية).

---

## هيكل الملفات

```
index.html              الصفحة الرئيسية للموقع
config.js               ← ضع هنا مفاتيح Supabase (الخطوة 2)
CNAME                   الدومين theifbe.com
assets/css/style.css    التصميم
assets/js/app.js        برمجة الموقع ولوحات التحكم
assets/img/             الشعار وشعارات الاعتمادات
supabase/01_schema.sql  إنشاء قاعدة البيانات وقواعد الحماية
supabase/02_seed.sql    المحتوى الأولي (البرامج، الخدمات، المكاتب، الإعدادات)
```

> إذا تُرك `config.js` فارغاً يعمل الموقع في **الوضع التجريبي**: كل شيء يعمل، لكن البيانات تُحفظ في متصفح الزائر فقط.

---

## الخطوة 1: إنشاء قاعدة البيانات على Supabase

1. ادخل إلى https://supabase.com وأنشئ حساباً، ثم **New project** (اختر منطقة قريبة مثل Frankfurt).
2. افتح ملف `supabase/01_schema.sql` وعدّل **آخر سطر**: ضع بريدك بدل `info@theifbe.com`، وهو البريد الذي ستدخل به كمدير.
3. في Supabase افتح **SQL Editor → New query**، الصق محتوى `01_schema.sql` كاملاً واضغط **Run**.
4. افتح Query جديدة، الصق محتوى `02_seed.sql` واضغط **Run**.

## الخطوة 2: ربط الموقع بقاعدة البيانات

1. في Supabase افتح **Project Settings → API**.
2. انسخ **Project URL** و **anon public key**.
3. افتح `config.js` وضعهما:

```js
window.IFBE_CONFIG = {
  supabaseUrl: "https://xxxxxxxx.supabase.co",
  supabaseAnonKey: "eyJhbGciOi..."
};
```

> مفتاح anon آمن للنشر العلني، لأن قواعد الحماية (RLS) داخل قاعدة البيانات هي التي تمنع الوصول. **لا تضع أبداً مفتاح `service_role` في الموقع.**

## الخطوة 3: إعدادات تسجيل الدخول في Supabase

في **Authentication → URL Configuration**:
- **Site URL**: `https://theifbe.com`
- **Redirect URLs**: أضف `https://theifbe.com/*` و `https://www.theifbe.com/*`

في **Authentication → Providers → Email**:
- اترك **Confirm email مفعّلاً**. هذا ضروري للأمان، لأنه يمنع أي شخص من إنشاء حساب ببريد مدير أو طالب لا يملكه.

> خدمة البريد المجانية في Supabase تسمح بعدد قليل من الرسائل في الساعة. عند التشغيل الفعلي اربط بريد الدومين من **Authentication → Emails → SMTP Settings** (مثلاً Zoho Mail أو Google Workspace أو Resend) حتى تصل رسائل التأكيد واستعادة كلمة المرور من `info@theifbe.com`.

## الخطوة 4: الرفع على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `ifbe-site`).
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع، بما فيها `CNAME` و `.nojekyll`.
3. من **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)**
   - Custom domain: `theifbe.com` ثم فعّل **Enforce HTTPS** بعد ظهور الشهادة.

## الخطوة 5: ربط الدومين theifbe.com

عند مزوّد الدومين (DNS) أضف السجلات التالية:

| النوع | الاسم | القيمة |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | `اسم-حسابك.github.io` |

قد يستغرق التفعيل من دقائق إلى 24 ساعة.

## الخطوة 6: أول دخول كمدير

1. افتح الموقع ← **تسجيل الدخول ← إنشاء حساب**.
2. استخدم نفس البريد الذي وضعته في آخر سطر من `01_schema.sql`، واختر كلمة مرور.
3. افتح رابط التأكيد الذي يصلك على البريد، ثم سجّل الدخول. ستُفتح لوحة الإدارة.

## كيف يعمل النظام

**إضافة مشرف جديد:** من لوحة الإدارة ← المشرفون ← إضافة بريده. بعدها ينشئ الشخص حساباً بنفس البريد.

**تسجيل طالب:**
- من لوحة الإدارة ← الطلاب ← إضافة جديد، مع بريد الطالب. أو اقبل طلب تقديم فيتحول صاحبه إلى طالب تلقائياً.
- ثم ينشئ الطالب حساباً بنفس البريد، فتظهر له لوحته وشهاداته وفواتيره فقط.

**إصدار شهادة:** من لوحة الإدارة ← الطلاب ← إصدار شهادة، أو من قسم الشهادات. يُولّد رقم الشهادة تلقائياً، ويمكن لأي شخص التحقق منه من صفحة "التحقق من الشهادة".

**ما يراه كل نوع مستخدم (تفرضه قاعدة البيانات نفسها):**

| | الزائر | الطالب | المدير |
|---|---|---|---|
| البرامج، الخدمات، المكاتب، النصوص | قراءة | قراءة | تحكم كامل |
| التحقق من شهادة برقمها | ✓ | ✓ | ✓ |
| إرسال طلب تقديم أو رسالة تواصل | ✓ | ✓ | تحكم كامل |
| بيانات الطلاب والشهادات والفواتير | ✗ | بياناته فقط | تحكم كامل |
| تعديل التقدّم أو الحالة أو الشهادات | ✗ | ✗ | ✓ |

**النسخ الاحتياطي:** من لوحة الإدارة ← الإعدادات ← النسخ الاحتياطي. ويحتفظ Supabase أيضاً بنسخ يومية في الخطط المدفوعة.

## تعديل الكود محلياً

لا يحتاج الموقع إلى أي أدوات بناء. افتح `index.html` مباشرة أو شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
